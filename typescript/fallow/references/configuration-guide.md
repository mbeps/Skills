# Fallow: Configuration Guide

This reference provides a comprehensive guide to configuring Fallow, including file formats, discovery precedence, auto-detected plugins, configuration schema options, and component library exemptions.

---

## 1. Zero-Config Philosophy & File Precedence

Fallow is designed to work out of the box with zero configuration for modern frameworks (Next.js, Vite, Vitest, React, Biome, Drizzle, etc.). It scans `package.json` and directory structure to activate built-in framework plugins automatically.

When customization is needed (e.g. custom entry points, component library barrel exemptions, rule severities), Fallow checks configuration files in this exact precedence order:

1. `.fallowrc.json` (Parsed as JSONC: comments and trailing commas allowed)
2. `.fallowrc.jsonc` (Explicit JSONC extension)
3. `fallow.toml`
4. `.fallow.toml`

### Generating Configuration
```bash
# Initialize a starter .fallowrc.json
fallow init

# Generate TOML format
fallow init --toml

# Analyze codebase shape and print recommended config + taste decisions
fallow recommend
fallow recommend --format json
```

## 2. Configuration Schema Overview

```json
{
  "$schema": "https://raw.githubusercontent.com/fallow-rs/fallow/main/schema.json",
  "entry": [
    "scripts/*.ts",
    "workers/*.ts"
  ],
  "ignorePatterns": [
    "evaluations/**",
    "graphify-out/**",
    "tmp/**",
    "**/*.generated.ts"
  ],
  "ignoreExports": [
    {
      "file": "components/ui/**",
      "exports": ["*"]
    }
  ],
  "ignoreDependencies": [
    "@blocknote/core",
    "hast-util-sanitize",
    "@types/node"
  ],
  "duplicates": {
    "minOccurrences": 3,
    "minTokens": 50,
    "minLines": 5,
    "mode": "mild"
  },
  "health": {
    "maxCyclomaticComplexity": 20,
    "maxCognitiveComplexity": 15,
    "maxCrap": 30,
    "maxUnitSize": 60
  },
  "rules": {
    "unused-files": "error",
    "unused-exports": "error",
    "unused-types": "error",
    "unused-dependencies": "warn",
    "unused-dev-dependencies": "warn",
    "circular-dependencies": "error",
    "unresolved-imports": "error",
    "unlisted-dependencies": "error"
  },
  "typeAware": {
    "enabled": false
  }
}
```

## 3. Key Configuration Properties

### `entry`
Array of root-relative glob patterns for entry points outside framework conventions.
- Next.js pages, layouts, route handlers, server actions, and middleware are detected automatically by the Next.js plugin.
- In Next.js App Router repositories without a `src/` folder, omit the default `"src/index.*"` patterns generated by starter configs and specify auxiliary entry points like `"scripts/*.ts"` or `"workers/*.ts"`.

### `ignorePatterns`
Array of globs excluded from analysis completely.
- Fallow automatically excludes `node_modules`, `dist`, `build`, `.git`, `coverage`, and minified files.
- Add project-specific non-production directories: `["evaluations/**", "graphify-out/**", "tmp/**"]`.
- Negation (`!`) un-ignores files under ignored paths: `["!src/policy/coverage/**"]`.

### `ignoreExports` (Component Libraries & Barrels)
Exempts exported symbols from `unused-export` checks for specific file globs.
- Designed specifically for design system components (e.g. Shadcn UI, Radix UI primitives) in `components/ui/**` where files export standard primitives (`DropdownMenuCheckboxItem`, `AlertDialogOverlay`, etc.) intended for reuse:
  ```json
  "ignoreExports": [
    {
      "file": "components/ui/**",
      "exports": ["*"]
    }
  ]
  ```
- Can also target specific named exports:
  ```json
  "ignoreExports": [
    {
      "file": "lib/utils.ts",
      "exports": ["cn", "formatDate"]
    }
  ]
  ```

### `ignoreDependencies`
Array of package names or globs excluded from both `unused-dependency` and `unlisted-dependency` checks:
- Packages imported directly in source but declared as transitive dependencies of a parent package (e.g. `@blocknote/core` via `@blocknote/mantine`, `hast-util-sanitize` via `rehype-sanitize`).
- Native binaries or runtime tools used only by build scripts: `["@emnapi/*", "dotenv-cli"]`.

### `duplicates`
Controls the copy-paste detector (`fallow dupes`):
- `minOccurrences`: Minimum clone instances required before reporting. Set to `3` to filter pair-only clones and focus on widespread duplication.
- `minTokens`: Minimum AST token count per clone (default 50).
- `minLines`: Minimum line count per clone (default 5).
- `mode`: Clone sensitivity mode:
  - `"mild"` (default): Standard syntactic clone matching.
  - `"strict"`: Exact character/structure match.
  - `"semantic"`: Normalizes identifiers and expressions to detect clone logic where variable names differ.

### `rules`
Sets rule severities: `"error"` (fails CI exit code 1), `"warn"` (reports advisories without failing), or `"off"` (silenced completely).

| Rule Key | Default | Description |
|---|---|---|
| `unused-files` | `error` | Source files unreached from any entry point |
| `unused-exports` | `error` | Exported symbols with zero references |
| `unused-types` | `error` | TypeScript type/interface exports with zero references |
| `unused-dependencies` | `error` | Packages in `dependencies` never imported |
| `unused-dev-dependencies` | `warn` | Packages in `devDependencies` never imported |
| `circular-dependencies` | `error` | Module import cycles |
| `unresolved-imports` | `error` | Imports targeting nonexistent modules/paths |
| `unlisted-dependencies` | `error` | Imported packages missing from `package.json` |
| `dev-dependencies-in-production` | `warn` | Packages in `devDependencies` imported in production source |
| `test-only-dependencies` | `warn` | Packages in `dependencies` only used in test files |
| `private-type-leaks` | `off` | Exported function/type referencing unexported private type |

## 4. Cache Management (`.fallow/`)

Fallow caches module extraction, AST parsing, and git churn data in the `.fallow/` directory in the repository root.
- **Git Ignore**: Always add `.fallow/` to `.gitignore`.
- **Relocating Cache**: Set `FALLOW_CACHE_DIR` or `"cache": { "dir": ".cache/fallow" }`.
- **Bypassing Cache**: Pass `--no-cache` to force a cold scan.
