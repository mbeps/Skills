# Code Smells Diagnostic Evaluation Matrix

Authoritative diagnostic catalogue mapping observed symptoms and code smells to underlying architectural defects, detection heuristics, evidence criteria, and evaluation domains.

Use this matrix during codebase evaluation to diagnose root causes objectively and provide specific, evidence-backed findings.

---

## 1. Architectural & Structural Smells

| Smell / Symptom | Detection Heuristic & Thresholds | Diagnostic Evidence Required | Affected Module | Severity |
|---|---|---|---|---|
| **Circular Dependency (`A ↔ B`)** | Bidirectional imports between modules or packages; madge/dpdm cycle report | Import cycle path between files, AST import traces | `architecture-design-analysis` | **High** |
| **Peer Domain Cycle** | Feature modules importing each other horizontally instead of sharing via foundational tier | Cross-feature relative imports (`../featureB/`) | `architecture-design-analysis` | **High** |
| **Storage Impedance Mismatch** | Specialised workloads (vectors, text search, timeseries) forced into relational tables | JSON blob columns with manual scans, custom search SQL | `architecture-design-analysis` | **Medium** |
| **Monolithic Context / God Provider** | Single provider holding authentication, UI modals, websocket state, and domain caches | React context or singleton store with $>15$ unrelated fields | `architecture-design-analysis`, `ui-component-analysis` | **High** |
| **Direct Persistence Coupling** | HTTP handlers, route handlers, or UI components executing direct DB queries inline | SQL strings or raw ORM calls in controller/route files | `architecture-design-analysis` | **High** |
| **Distributed Resource Deletion Leaks** | Relational cascade deletes database row but leaves orphaned cloud files/buckets | Foreign key `ON DELETE CASCADE` lacking S3/storage cleanup hook | `architecture-design-analysis`, `security-audit` | **High** |
| **Monolithic Server Entrypoint** | God bootstrap file inlining routing, middleware, database initialisation, and error handling | Single `server.ts` or `app.py` exceeding 300 LOC with $>5$ concerns | `architecture-design-analysis` | **Medium** |
| **Multi-Action God Modules (Action Sprawl)** | Monolithic controller/actions file bundling 8–20 procedures across 350+ LOC | Single actions file exporting $>5$ disparate procedures, shared mock pollution | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Unbounded Recursive Tree Depth** | Arbitrary comment or hierarchy depth without recursion guard, risking stack overflow | Recursive self-referencing model lacking max-depth check | `architecture-design-analysis` | **High** |
| **Query Cardinality Mismatch** | Exact-one operator (`.single()`) invoked on optional zero-or-one relations | Uncaught PGRST116 / 406 runtime exceptions when records are absent | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Dual-Format Identifier Mismatch** | Interleaving legacy integer IDs and UUIDs across relational schema joins | Explicit type casting (`parseInt(id)`) and join failure workarounds | `architecture-design-analysis`, `codebase-consistency` | **High** |
| **N+1 Relational Hydration Waterfall** | Sequential item-by-item fetches in loops across bare stores lacking batch queries | `for` loop awaiting individual queries per item instead of batch queries | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Client-Server Environment Bleed** | Monolithic env file bundling server secrets with client-exposed build constants | Private keys prefixed with client build prefixes or imported in UI | `architecture-design-analysis`, `security-audit` | **Critical** |
| **Subsystem / Transport Retirement** | Deprecated execution transport (e.g. legacy stdio/gRPC alongside HTTP) still maintained | Dual entrypoints maintaining parallel handling logic | `architecture-design-analysis` | **Medium** |
| **Unserialized Entity Queue Concurrency** | Asynchronous background jobs/queues mutating an entity lacking entity-scoped concurrency keys/locks | Event handlers or queue functions triggering concurrent parallel mutations on the same entity | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Polyglot Storage Compensation Absence** | Multi-store mutations (relational DB + object storage / search index) lacking rollback compensation | DB insert followed by external storage upload lacking catch-block compensating deletion | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Container Host-Gateway Callback Deadlock** | Background workers or sidecars in container networks calling host endpoints via hardcoded loopback | Network timeouts (`dial tcp ... i/o timeout`) on container callback routes | `architecture-design-analysis` | **High** |
| **Unpersisted Pipeline Mutation (Silent State Loss)** | Multi-step workflow/pipeline executing mutations without verifying artifact persistence before completion | Step reporting success while omitting updated output artifact from persistent storage | `architecture-design-analysis`, `quality-analysis` | **Critical** |
| **Multi-Tier Payload Limit Disparity** | Asymmetric upload size limits configured across reverse proxies, edge middleware, and backend handlers | Uploads exceeding 1MB dropped at edge middleware (`middlewareClientMaxBodySize`) while backend action allows 50MB | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Decoupled Identity Synchronization (Missing JIT Provisioning)** | Decoupling auth identity providers from internal user tables without lazy reconciliation on authenticated requests | First-login mutations failing with "User not found" due to webhook delays or dropped triggers | `architecture-design-analysis`, `security-audit` | **High** |
| **Static Cache Staleness on Dynamic Dashboards** | Stateful or data-mutating administrative views missing explicit dynamic rendering declarations | Dashboard displaying stale cached metrics because page lacks `dynamic = 'force-dynamic'` or revalidation tags | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Generic Trigger Column Assumption on Junction Tables** | Attaching schema-wide audit triggers (e.g. `set_updated_at`) to junction/association tables lacking target columns | Insert/update mutations failing with database column missing exceptions (e.g. `record "new" has no field "updatedAt"`) | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Denormalized Replica Desynchronization** | Mutating canonical entities without updating distributed denormalized projections or caches | Canonical document/row updated while child snippets, summary counts, or replicas retain stale data | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Database Trigger Storage Boundary Inversion** | Direct SQL triggers (`DELETE FROM storage.objects`) attempting to manage external blob storage tables | Entity deletions failing with permission/foreign key errors on storage tables; transaction rollback | `architecture-design-analysis` | **High** |
| **Dynamic Route-Level 404 Boundary Omission** | Parameterized entity routes (`[id]`) lacking route-level `not-found.tsx` handlers | Non-existent entity queries falling back to uninformative generic root 404 pages or unhandled errors | `architecture-design-analysis`, `ui-component-analysis` | **Medium** |
| **Layout Auth Scope Boundary Mismatch** | Authenticated queries or stateful user components mounted inside global/root layout tiers instead of protected subroute layouts | Unauthenticated visitors trigger auth errors or unhandled redirects during root initialisation | `architecture-design-analysis`, `security-audit` | **High** |
| **Isomorphic Bundle Server Secret Parsing** | Parsing and validating server-only secret environment variables at module top-level in files imported by client bundles | Client-side compilation / bundler crashes; leak of schema evaluation into browser runtime | `architecture-design-analysis`, `security-audit` | **Critical** |
| **Dynamic Route Handler Prerendering Deadlock** | Server route handlers or pages accessing request headers, cookies, or search parameters during static generation without dynamic opt-in | Build failures: `DYNAMIC_SERVER_USAGE` errors when static export or prerender evaluates dynamic request APIs | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Static Route Parameter Export Omission** | Dynamic parameterized routes (`[id]`, `[slug]`) lacking `generateStaticParams` / `getStaticPaths` in static export or SSG targets | Pages render on-demand in local dev server but fail with 404 Not Found or static generation errors in production deployment | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Relative Asset Path Deep-Route Fragility** | Stripping leading root slashes (`BASE.slice(1)`) or declaring asset paths as relative strings rather than root-relative | Assets load cleanly on root pages (`/projects`) but 404 on nested subroutes (`/projects/item/report`) due to subpath relative resolution | `architecture-design-analysis`, `codebase-consistency` | **High** |
| **Static Data Map Relational Asymmetry & Orphan Keys** | Maintaining static databases/seed maps with manual bidirectional relationships without automated symmetry tests | Entity A links to Entity B but Entity B does not link to Entity A; orphan references to deleted entities break rendering | `architecture-design-analysis`, `quality-analysis` | **Medium** |
| **Auth Adapter Schema Incompleteness / Migration Drift** | Database schema lacking model fields (`idToken`, `password`, `Verification` table) expected by auth framework adapter, or enforcing unserviced constraints (email verification without SMTP) | Runtime database missing column exceptions on OAuth login or user onboarding deadlock | `architecture-design-analysis`, `security-audit` | **High** |
| **Eager Browser SDK Instantiation in Universal Bundles** | Instantiating client-only SDKs (socket connections, Pusher client, WebRTC) at top-level module scope in files shared across server and client | Node.js deprecation warnings (`DEP0169 url.parse`), SSR crashes (`window is not defined`), or unwanted build-time connections | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Mega-Dispatcher Degradation & Return Drift** | Consolidating $>10$ fine-grained operations into coarse dispatchers without discriminated unions; returning loose untyped dicts or strings | Dispatcher routing lacking action-to-schema mapping, untyped return payloads, missing promised model fields | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Facade Parameter Starvation & Argument Inversion** | Facade wrapper omitting optional arguments (`count=None`) or transposing positional arguments (`(target, source)`) | Downstream domain service receives explicit None ignoring defaults, or overwrites target with source name | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Opaque Dictionary Contract Erosion** | Replacing declared Pydantic/TypeScript response models with untyped `dict[str, Any]` or `list[dict]` in public APIs | OpenAPI/MCP JSON schemas degrade into unvalidated `{ "type": "object" }`, runtime type loss | `architecture-design-analysis`, `quality-analysis` | **High** |
| **Destructive Sibling Document / Sheet Overwrite** | In-place mutation saving partial sub-models back to target file path, destroying unreferenced sibling sheets or metadata | Output file loses sibling sheets, formulas, or archive members after editing single sheet/partition | `architecture-design-analysis`, `security-audit` | **Critical** |
| **Cascading Referential Integrity Breakage** | Renaming or mutating sheets, tables, or entities without updating cross-references; asymmetric join keys (`left_on != right_on`) or duplicate columns | Spreadsheets showing `#REF!` / `#NAME?`, dropped records in asymmetric table joins, or unhandled merge conflicts | `architecture-design-analysis`, `quality-analysis` | **High** |

## 2. Code Quality & Complexity Smells

| Smell / Symptom | Detection Heuristic & Thresholds | Diagnostic Evidence Required | Affected Module | Severity |
|---|---|---|---|---|
| **High Cognitive Complexity** | SonarQube cognitive complexity $>15$ (warning) or $>30$ (critical hotspot) | Nesting depth $>3$, multiple structural jumps, break/continue | `quality-analysis` | **Critical/High** |
| **Deeply Nested Conditionals (Arrow Code)** | Nesting level $\ge 4$ indentation blocks (`if` inside `for` inside `if`) | Code pyramid indentation, missing early guard returns | `quality-analysis` | **High** |
| **Long Method / God Function** | Single function exceeding 50 lines or handling $>3$ execution phases | Function LOC, lines spanning validation + computation + persistence | `quality-analysis` | **High** |
| **God Class / Object** | Single class with $>10$ public methods or $>500$ LOC handling $>1$ domain concern | Class method count, disparate imported dependencies | `quality-analysis` | **High** |
| **Primitive Obsession** | Raw strings/numbers representing domain concepts (emails, currency, postal codes) | Missing Value Objects, repeated ad-hoc regex validation | `quality-analysis` | **Medium** |
| **Long Parameter List** | Functions taking $\ge 4$ positional arguments | Function signature inspection; arguments susceptible to positional drift | `quality-analysis` | **Medium** |
| **Feature Envy** | Method calls more methods on another object than on its own enclosing class | Call graph inspection, accessing multiple getters on foreign object | `quality-analysis` | **Medium** |
| **Linear Scan on Static Collections** | Repeated $O(N)$ scans (`.find()`, `.filter()`) on static or read-heavy datasets | Linear search loops inside hot rendering or query paths without reverse index | `quality-analysis` | **Medium** |
| **Runtime Static Data Enrichment Loop** | Dynamic runtime loops inspecting disk assets or computing fallbacks on every render | Asynchronous filesystem I/O executing inside component render passes | `quality-analysis`, `ui-component-analysis` | **Medium** |
| **Unstructured Temporal Obsession** | Storing dates as formatted strings (`"Sep 2022 - Present"`) in domain models | Regex string splitting on dates; inability to sort chronologically | `quality-analysis`, `codebase-consistency` | **Medium** |
| **Naive Additive Quota Checks** | Quota evaluated as `current + new > limit` instead of net delta on file replacement | False quota rejection errors when users update existing assets | `quality-analysis`, `security-audit` | **High** |
| **Read-Modify-Write Concurrency Races** | Non-atomic `SELECT` followed by in-memory logic followed by `UPDATE` | Concurrent mutation without atomic SQL expressions or row locking | `quality-analysis`, `security-audit` | **Critical** |
| **Silent Input Degradation / Swallowed Errors** | Empty `catch` blocks or silent omission of unsupported capabilities | `catch (e) {}` with no logging or typed error rethrow | `quality-analysis` | **High** |
| **Unshielded Resource Handles (I/O Leaks)** | Unclosed database connections, file handles, or network sockets lacking finally/disposal | Missing `try...finally`, `using`, or auto-closable wrappers | `quality-analysis` | **High** |
| **Untyped Bag-of-Keys / Opaque Parameters** | `Record<string, any>`, `dict`, or `object` passed across system boundaries | Missing schema validation (Zod, Pydantic) at API/module borders | `quality-analysis` | **High** |
| **High CRAP Score** | $\text{comp}^2 \cdot (1 - \text{cov})^3 + \text{comp} > 30$ | Cyclomatic complexity $>10$ with $<50\%$ test coverage | `quality-analysis` | **High** |
| **Check-Then-Act Upsert Race** | Non-atomic `SELECT` followed by `if exists UPDATE else INSERT` in application code | Multi-step query/insert sequence without database-level `ON CONFLICT DO UPDATE` or locking | `quality-analysis`, `security-audit` | **Critical** |
| **Shared Registry Premature Eviction** | Unconditional `registry.delete(key)` in cleanup callbacks of shared registries | Resource pool removing active handles registered by subsequent concurrent requests | `quality-analysis` | **High** |
| **Unbounded Agent Delegation / Context Bloat** | Tool results injecting full transcripts, file dumps, or unparsed logs directly into history | Large unpaginated/uncondensed tool outputs causing rapid context exhaustion | `quality-analysis` | **High** |
| **Silent Synthesis Drop on Step Budget Exhaustion** | Multi-step agent loops stopping on step limits without a fallback synthesis pass | Execution loop finishing on `finishReason: "tool-calls"` with empty text output | `quality-analysis` | **High** |
| **Unresolved Tool-Call Protocol Parity Violation** | Tool-call parts in message history lacking paired tool-result parts (e.g. after errors or interrupts) | Assistant message containing `tool-call` with no matching `tool-result` in thread history | `quality-analysis`, `security-audit` | **Critical** |
| **Relational Join Polymorphism Fragility** | Accessing joined properties assuming strictly single object without checking for array shape | Uncaught `TypeError: Cannot read properties of undefined` when joined relation returns `[{ id }]` | `quality-analysis`, `architecture-design-analysis` | **High** |
| **Binary Base64 Serialization Bloat** | Converting multi-megabyte binary uploads to base64 Data URLs for JSON payloads instead of streaming multipart `FormData` | Heap allocation spikes, ~33% payload inflation, exceeding server JSON parsing limits | `quality-analysis`, `ui-component-analysis` | **Medium** |
| **Event-Handler Parameter Bleed (SyntheticEvent Poisoning)** | Passing action callbacks with optional parameters directly to DOM event listeners (`onClick={fn}`) | Target function receives SyntheticEvent as first argument, causing `router.push('/[object Object]')` | `quality-analysis`, `ui-component-analysis` | **High** |
| **Closed-Enum Error Dictionary Assumption** | Accessing static error mapping dictionaries without fallback to raw error message or generic string | Code indexing `ERROR_MAP[err.code]` without chained `err.message` fallback, causing blank error UI | `quality-analysis` | **High** |
| **Bulk IN-Clause Parameter Overflow** | Unpartitioned dynamic ID arrays passed to datastore IN queries exceeding driver or query limits | Query execution crashing on large collections (e.g. $>10$ items in document stores or $>999$ in SQL) | `quality-analysis`, `security-audit` | **High** |
| **Server Action Return Type Boolean Ambiguity** | Mutation action returning bare boolean `false` instead of structured Result envelope | Caller unable to diagnose or display specific failure reasons (`toast.error(error)`) | `quality-analysis`, `architecture-design-analysis` | **Medium** |
| **Asynchronous Route Parameter Synchronous Dereference** | Synchronously accessing route properties (`params.id`, `searchParams.q`) that are asynchronous Promises in modern frameworks | Runtime error / deprecation warning: accessing properties on Promise directly yields undefined or crashes in production | `quality-analysis` | **High** |
| **Unawaited Asynchronous Recursion / Floating Cascade** | Calling recursive async operations or multi-entity cascades without `await` | Parent mutation/handler returns before child records update; orphaned descendants, transaction race conditions | `quality-analysis` | **High** |
| **Markdown / Text Regex Code Span Ingestion** | Global regex replacements on markdown partitioning only on fenced blocks without shielding inline backtick spans | Inline code snippets (e.g. `` `$$x$$` ``) or formula variables inside paragraphs corrupted by preprocessor replacement | `quality-analysis` | **Medium** |
| **Naive Date Difference & Ongoing Temporal Boundary Off-by-One** | Calculating tenure/duration using naive year difference or failing to dynamically resolve active ongoing roles | Work experience duration showing incorrect months, negative values, or failing to calculate active positions | `quality-analysis` | **Medium** |
| **Caught Exception Shape Assumption in Error Handlers** | Destructuring or indexing nested error properties (e.g. `error.errors[0]` vs `error.issues[0]` in Zod) without runtime type narrowing or optional chaining | `TypeError: Cannot read properties of undefined` in catch blocks turning 400 errors into 500 crashes | `quality-analysis` | **High** |
| **Schema Nullability vs Optionality Mismatch** | Optional validation schema fields declared with `.optional()` rejecting explicit `null` values from databases or form resets | `ZodError: Expected string, received null` during form submission or database row deserialization | `quality-analysis`, `codebase-consistency` | **High** |
| **Foreign Library Polymorphic Return Shape Trap** | Indexing library queries assuming static 2D dimensions; single cell collapses to scalar or empty sheet returns None | Runtime `TypeError: 'Cell' object is not subscriptable` or `IndexError` on boundary-dimension inputs | `quality-analysis` | **High** |
| **Destructive Property Setter Hook on Null/Empty Values** | Assigning null/empty primitive to composite document/chart property triggering underlying XML deletion setter hooks | Setting `title = None` deletes XML element tree, corrupts Excel serialization or wipes child formatting | `quality-analysis` | **High** |
| **Deep-Branch Phantom Dependency (Unimported Symbol)** | Standard library or external dependencies imported inside deep conditional branches or forgotten, causing runtime `NameError` | Rare execution branches (e.g. IRR financial analysis, regex filters) crashing on unimported symbols in production | `quality-analysis` | **High** |
| **Operator & Syntax Rigidity** | Parser strictly checking exact operator string (rejecting `==` for `=` or requiring strict case on keywords) | Rejection of valid user/agent queries with syntax errors; failure to normalize operators into domain enums | `quality-analysis` | **Medium** |
| **Locale-Heuristic Canonical Format Corruption** | Ingesting standardized ISO 8601 strings or numeric data using locale guessing heuristics (`dayfirst=True`) that corrupt dates | ISO date `"2024-05-01"` parsed as Jan 5th; comma-decimal numbers parsed with wrong magnitudes | `quality-analysis`, `codebase-consistency` | **High** |
| **Partial State Mutation & Half-Baked Feature Persistence** | Multi-stage operation failing mid-pipeline leaving dirty in-memory state, or dropping persistence flags (`output_file`) upon completion | Output file unwritten or stale despite reported success; partially mutated state corrupting subsequent requests | `quality-analysis`, `security-audit` | **Critical** |

## 3. Redundancy & Duplication Smells

| Smell / Symptom | Detection Heuristic & Thresholds | Diagnostic Evidence Required | Affected Module | Severity |
|---|---|---|---|---|

## 7. Dependency & Tooling Smells

| Smell / Symptom | Detection Heuristic & Thresholds | Diagnostic Evidence Required | Affected Module | Severity |
|---|---|---|---|---|
