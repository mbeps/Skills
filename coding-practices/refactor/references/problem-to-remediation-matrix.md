# Refactoring Problem-to-Remediation Matrix

## Overview
This matrix serves as the comprehensive diagnostic index for code smells, architectural anti-patterns, complexity hotspots, and structural defects. Find the observed symptom or code smell in the left column to locate the underlying root cause, the recommended remediation pattern, and the authoritative deep-dive reference document.

---
