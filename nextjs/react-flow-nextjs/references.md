# React Flow v12 References & API Cheatsheet

## 1. Migrating from v11 (`reactflow`) to v12 (`@xyflow/react`)

| Feature / API             | v11 (`reactflow`)                   | v12 (`@xyflow/react`)                           |
| ------------------------- | ----------------------------------- | ----------------------------------------------- |
| **Package name**          | `npm i reactflow`                   | `npm i @xyflow/react`                           |
| **CSS Import**            | `import 'reactflow/dist/style.css'` | `import '@xyflow/react/dist/style.css'`         |
| **Coordinate conversion** | `project({ x, y })`                 | `screenToFlowPosition({ x, y })`                |
| **Node Dimensions**       | `node.width`, `node.height`         | `node.measured?.width`, `node.measured?.height` |
| **Custom edge updater**   | `updateEdge(oldEdge, newConn)`      | Built-in edge reconnecting hooks                |
| **SSR / Hydration**       | Frequent window mismatch warnings   | Improved Next.js App Router support             |

## 2. Core TypeScript Types (`@xyflow/react`)

### Node Definition
```ts
import type { Node } from "@xyflow/react";

export type CustomNodeData = {
  variableName?: string;
  credentialId?: string;
  systemPrompt?: string;
};

export type WorkflowNode = Node<CustomNodeData, "CUSTOM_TYPE">;
```

### Edge Definition
```ts
import type { Edge, Connection } from "@xyflow/react";

export type WorkflowEdge = Edge<{
  condition?: string;
}>;

// Connection payload generated by onConnect
export interface Connection {
  source: string;
  target: string;
  sourceHandle: string | null;
  targetHandle: string | null;
}
```

### `useReactFlow()` Instance Methods
```ts
const {
  getNodes,                // () => Node[]
  setNodes,                // (nodes: Node[] | (prev: Node[]) => Node[]) => void
  getEdges,                // () => Edge[]
  setEdges,                // (edges: Edge[] | (prev: Edge[]) => Edge[]) => void
  addNodes,                // (nodes: Node | Node[]) => void
  addEdges,                // (edges: Edge | Edge[]) => void
  screenToFlowPosition,    // (position: XYPosition, options?: { snapToGrid?: boolean }) => XYPosition
  flowToScreenPosition,    // (position: XYPosition) => XYPosition
  fitView,                 // (options?: FitViewOptions) => Promise<boolean>
  zoomIn,                  // (options?: ZoomInOutOptions) => void
  zoomOut,                 // (options?: ZoomInOutOptions) => void
  setCenter,               // (x: number, y: number, options?: SetCenterOptions) => void
} = useReactFlow();
```

## 3. Keyboard & Mouse Shortcuts

| Action               | Shortcut / Gesture                 | React Flow Prop / Config                      |
| -------------------- | ---------------------------------- | --------------------------------------------- |
| **Pan Canvas**       | Space + Drag OR Middle-Click Drag  | Default behavior                              |
| **Zoom Canvas**      | Ctrl/Cmd + Wheel OR Trackpad Pinch | `zoomOnScroll`, `zoomOnPinch`                 |
| **Box Select Nodes** | Shift + Click & Drag               | `selectionOnDrag={true}`, `panOnDrag={false}` |
| **Delete Selected**  | Backspace OR Delete                | `deleteKeyCode="Backspace"`                   |
| **Multi-Select**     | Shift + Click on individual nodes  | `multiSelectionKeyCode="Shift"`               |
